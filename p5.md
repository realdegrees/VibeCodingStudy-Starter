## Überblick
Ihre Aufgabe ist es, ein modernes Weather-Dashboard zu entwickeln. Sie erhalten eine Skeleton-App (leeres CSS, HTML-Grundgerüst und JavaScript-Dateien) und sollen daraus eine visuell ansprechende Wetter-Anwendung erstellen.

## Wichtige Hinweise zur Durchführung

### Entwicklungswerkzeug
- **Verwenden Sie ausschließlich GitHub Copilot** (Premium-Modell: Gemini 3 Pro)
- Sie dürfen Code auch manuell anpassen, die Hauptarbeit soll jedoch mit Copilot erfolgen

### Dokumentation
Am Ende der Entwicklung müssen Sie zwei Dinge abgeben:

1. **Copilot Chat-Session exportieren:**
   - Drücken Sie `Strg+Umschalt+P` (Windows/Linux) oder `Cmd+Shift+P` (Mac)
   - Suchen Sie nach "Export Chat"
   - Exportieren Sie die Chat Session als JSON

2. **Gesamten Projektordner zippen:**
   - Erstellen Sie eine ZIP-Datei des kompletten Ordners

## Technische Vorgaben

- **Nur HTML, CSS und JavaScript** (keine Frameworks)
- **Bibliotheken über HTML `<script>`-Tags** Erlaubt
- **Verwendung von Icons oder Bildern:** Erlaubt
- **API:** [Open-Meteo Weather API](https://open-meteo.com/en/docs) (kein API-Key erforderlich)
- **Skeleton-Dateien:**
  - `index.html` – HTML-Grundgerüst
  - `css/style.css` – leeres Stylesheet
  - `js/app.js` – Haupt-JavaScript-Datei
  - `js/config.js` – enthält Open-Meteo API-Adresse

## Ziel

Erstellen Sie innerhalb von maximal 2 Stunden ein **visuell ansprechendes Weather-Frontend**, das folgende Mindestanforderungen erfüllt:

### Must-Have Features

1. **Standortsuche**
   - Suchfeld für Eingabe eines Stadtnamens

2. **Aktuelle Wetterdaten des Standorts**
   - Luftfeuchtigkeit
   - Windgeschwindigkeit
   - Gefühlte Temperatur
   - Regenwahrscheinlichkeit

3. **Stündliche Vorhersage der Wetterdaten**
   - Vorhersage für den heutigen Tag (stündlich)

Die Visuelle Darstellung der Daten ist ihnen überlassen.

4. **Benutzerfreundliches Design**
   - Sauberes, klares Layout
   - Ansprechende visuelle Aufbereitung

### Optional (Nice-to-Have)

- Einheitenwechsel (°C/°F)
- Dynamisches Styling passend zum Wetter
- Mehrere Tage Vorhersage
- Weitere Metriken (UV-Index, Luftdruck, etc.)
- Ihre eigenen kreativen Ideen!
